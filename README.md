# Fishing House

Уютная пиксельная онлайн-игра: поле у реки и причал рыбака. Середина мира взята с картинки-образца (дом с неё пока убран — на его месте поляна, лес вокруг поляны тоже — на его месте трава), вокруг дорисованы поле, река и дорога; по миру ходит рыбак в жёлтом плаще: носит ведро и рюкзак и ловит рыбу с причала. Рядом ходят и рыбачат другие игроки.

Сейчас в игре есть регистрация и вход, общий мир со сменой дня и ночи и погодой, герой, ведро, рюкзак четырёх расцветок и рыбалка с пятью видами рыб. Улов и место героя хранятся на сервере, профиль любого игрока открывается по его id. Продажи улова, магазина и построек пока нет.

## Из чего сделано

| Часть | Что | Папка |
|---|---|---|
| Сайт и игра в браузере | Nuxt 4, Vue 3, TypeScript, Pinia; игра рисуется на canvas | `app/` |
| API | Nuxt (Nitro): вход, регистрация, профили, билеты в игру | `app/server/` |
| Игровой сервер | Colyseus: общий мир, проверка ходов, рыбалка | `game-server/` |
| База | PostgreSQL + Drizzle ORM | `shared/src/server/`, миграции в `shared/drizzle/` |
| Общий код | карта, рыбы, правила рыбалки, протокол | `shared/` |
| Продакшен | Docker Compose + Caddy на одном VPS | `docker-compose.yml`, `Caddyfile`, `Dockerfile` |

Подробнее об устройстве и правилах проекта — в [CLAUDE.md](CLAUDE.md).

## Как запустить у себя

Нужны Node.js 22+ и Docker (только для базы и Redis).

```bash
npm install
cp .env.example .env        # поменяй секреты: NUXT_SESSION_PASSWORD и GAME_SECRET
npm run db:up               # Postgres и Redis в Docker
npm run db:migrate          # таблицы в базе
npm run dev                 # сайт и игровой сервер вместе
```

Открой http://localhost:3000, зарегистрируйся и нажми «Играть». Чтобы увидеть мультиплеер, открой игру во втором браузере (или в окне инкогнито) под другим игроком.

Если Postgres уже стоит у тебя без Docker, пропусти `npm run db:up` и поправь `DATABASE_URL` в `.env`.

### Проверки

```bash
npm test                      # правила рыбалки, ведро, билеты
npm run typecheck             # типы во всех пакетах
npm run check                 # тесты и типы разом
npm run smoke:own -w game-server  # бот регистрируется, ходит, носит ведро и ловит рыбу через настоящий сервер
npm run check:all             # всё вместе — то же гоняет GitHub Actions на каждый пуш
```

Для `smoke:own` нужна только база: игровой сервер бот поднимает сам, на свободном порту. `npm run smoke -w game-server` гоняет того же бота через уже запущенный сервер (`npm run dev`).

## Как выложить на VPS

На сервере нужны Docker и домен, указывающий на него.

```bash
git clone … && cd Fishing-House
cp .env.example .env
# в .env: DOMAIN=твой.домен, POSTGRES_PASSWORD, NUXT_SESSION_PASSWORD, GAME_SECRET (openssl rand -hex 32)
docker compose up -d --build
```

Caddy сам получит HTTPS-сертификат. Внутри поднимутся сайт, два процесса игрового сервера, Redis и Postgres; миграции применятся перед стартом. Ещё процесс игрового сервера добавляется так: скопировать `game-2` в `docker-compose.yml` и строчку для него в `Caddyfile`.

Как это рассчитано на нагрузку: в одной комнате-причале до 50 игроков. Когда она заполнена, сервер открывает ещё одну такую же. Комнаты распределяются по процессам, процессы находят друг друга через Redis. Сервер рассылает состояние 10 раз в секунду, и только то, что изменилось.

## Как играть

Новый игрок начинает так: рыбак сидит на причале с удочкой, ведро и рюкзак стоят на поляне над берегом. Чтобы рыбу было куда класть, ведро нужно принести к причалу.

| Действие | Управление |
|---|---|
| Идти | `W` `A` `S` `D` или стрелки; клик или тап по миру — герой сам обойдёт препятствия |
| Взять или поставить ведро | `E` рядом с ведром; клик по ведру; с ведром в руке — клик по герою |
| Надеть или снять рюкзак | `Q` рядом с рюкзаком или с рюкзаком на спине; клик по рюкзаку |
| Выбрать другой рюкзак | кнопка «Рюкзак» слева внизу |
| Сесть рыбачить | `F` или `Пробел` у левого края причала, либо клик по этому месту |
| Забросить и подсечь | `F`, `Пробел` или клик по воде |
| Встать | `Esc`, клавиши движения или клик по земле |
| Показать разметку | `F2` или адрес `/play?debug` |
| Перевести часы и выставить погоду (в разработке) | нажать на часы справа вверху: ползунок и кнопки времени, погода, ветер |
| Остановить время суток только у себя (для проверки) | адрес `/play?hour=22` — любой час от 0 до 24 |

Все действия продублированы кнопками внизу экрана: на телефоне управление идёт через них и касания. Справа вверху — сколько игроков на причале; в списке имена ведут на их профили.

### Рыбалка

1. Сядь на край причала и забрось удочку. Ведро должно стоять рядом — на причале или у самого берега. Если сесть с ведром в руке, герой сам поставит его рядом.
2. Жди поклёвку: поплавок уйдёт под воду, над героем появится `!`. Бывают ложные тычки — поплавок дёргается, но это ещё не поклёвка.
3. Подсеки, пока рыба не сошла. Дёрнешь раньше — спугнёшь, опоздаешь — сорвётся.
4. Рыба летит в ведро, удочка забрасывается снова.

Когда клюёт, кто клюнул и успел ли ты подсечь, решает сервер, поэтому улов нельзя подделать из браузера.

| Рыба | Как часто клюёт | Вес | Время на подсечку |
|---|---|---|---|
| Плотва | 38% | 90–380 г | 1,25 с |
| Окунь | 26% | 120–650 г | 1,1 с |
| Карась | 20% | 180–950 г | 1,15 с |
| Щука | 11% | 0,9–4,8 кг | 0,85 с |
| Золотая рыбка | 5% | 60–240 г | 0,7 с |

Панель слева вверху показывает, что лежит в ведре. Из ведра торчат хвосты трёх последних пойманных рыб — их видно и другим игрокам.

### Рюкзак

Рюкзак лежит на поляне. Его можно надеть и ходить с ним, а потом снять — он ляжет на землю рядом с героем. Расцветок четыре: кожаный (тот, что на картинке), походный, морской и ягодный. Выбранную видят и другие игроки. Сесть рыбачить можно и с рюкзаком на спине. Пока это только внешний вид: предметы в рюкзаке не хранятся.

### День и ночь

Игровые сутки длятся 24 минуты: игровой час идёт минуту. Время берётся с часов сервера, поэтому у всех на причале оно одно; часы — справа вверху. К семи вечера небо рыжеет, к половине девятого наступает ночь: кадр темнеет и синеет. К четверти восьмого утра снова день. Дома на карте сейчас нет; когда он стоит, с семи вечера до шести утра в его окнах и в фонаре у двери горит свет, и возле него светло. Знак поклёвки и подсказки клавиш ночью не темнеют. На рыбалку время суток пока не влияет.

В разработке часы причала можно перевести: нажми на них справа вверху. Время меняет игровой сервер, поэтому оно меняется сразу у всех игроков, и дальше идёт с выбранного часа. Сдвиг живёт в памяти сервера — после его перезапуска время снова настоящее. В продакшене (`NODE_ENV=production`) перевод выключен и часы — просто надпись; явно включить или выключить его можно переменной `DEV_TOOLS` (`1` или `0`).

### Погода

Погода бывает трёх видов: ясно, пасмурно и дождь. Отдельно от неё дует или не дует ветер — он бывает в любую погоду. Погоду ведёт сервер, поэтому у всех на причале она одна; она написана рядом с часами. Меняется она раз в пять минут: примерно в половине случаев ясно, чуть больше четверти — пасмурно, остальное — дождь; ветер дует примерно в трети случаев.

- **Пасмурно** — свет серее и холоднее, краски бледнее, блики на воде гаснут.
- **Дождь** — ещё темнее, летят капли. На воде от каждой расходится круг и подпрыгивает брызга, на земле и листве — две брызги в стороны. Река в дождь бежит быстрее.
- **Ветер** — по кадру бегут светлые порывы и летят листья, дождь идёт косо.

Одна погода сменяет другую плавно, за несколько секунд. На рыбалку погода пока не влияет. В разработке её можно выставить в той же панели, что и часы: «Сама» и «Сам» возвращают погоду и ветер к расписанию.

### Профиль и прогресс

- Улов записывается в базу в момент подсечки, место героя, ведра и рюкзака — при выходе и раз в минуту.
- Профиль игрока — `/player/<id>`: имя, деньги, ведро, рекорды по видам и последние уловы. Его видит любой, кто знает id, вход не нужен. Свой профиль открывается из меню.
- Играть можно в одном окне: если открыть игру во втором, первое отключится.

## Как устроен мир

Образец `art/reference.webp` нарисован на сетке 240×320 «арт-пикселей» (по 3,75 px). Скрипт `tools/build-world.mjs` снимает с него эту сетку — получается та же картинка без размытых краёв. Игра рисует холст целым множителем чуть крупнее окна и ужимает до его размера, поэтому пиксели остаются ровными.

Сама карта `app/public/assets/world.png` больше картинки — 640×360, ровно 16:9: картинка стоит в середине у нижнего края, а по бокам и сверху её дорисовывает `tools/world-sides.mjs`. На экране 1920×1080 игра рисует карту ровно втрое крупнее, без ужимания; такая же копия лежит в `art/world-1920x1080.png`. Вместо леса вокруг поляны — поле (раздел `field` в `tools/world-shapes.mjs`): та же трава, что на поляне в середине, с пучками и цветами. Оно занимает бока, полосу над картинкой и всё, что на самой картинке было лесом выше поляны, — граница проведена ломаной `field.edge` по чистой траве, мимо тропинки и камней. Кустов на карте тоже нет: трава доходит до самой воды с земляным обрывом, как у поляны. Кусты картинки над рекой заменены травой внутри многоугольников `field.bushes`, а всё, что под рекой, — вода до нижнего края карты: у берега светлее, дальше (ниже ломаной `field.deepFrom`) — глубокая, тёмная, с редкими бликами; на картинке её заливают многоугольники `field.sea`. Камни, которые срезал край картинки (раньше их закрывали кусты), дорисованы целыми — `field.stones`. Лодки, сетей, ящика-ловушки, сумки на причале и грибов в траве нет: их стирает раздел `clutter` в `tools/world-shapes.mjs` — настил и сваи под ними дорисованы, на их месте вода или трава. Река идёт через всю карту. Из земляной тропинки у причала вправо за край карты уходит дорога — та же земля с плоскими камнями; старая тропинка картинки справа затёрта травой (`field.trail`), а изгиб дороги задаёт `sides.road`. Вода, трава и дорога рисуются цветами картинки. Код леса и кустов в сборке остался: с `field: null` по бокам снова встаёт лес с кустами у воды. План боков — берега реки, дорога, стыки с картинкой — лежит в `sides` в `tools/world-shapes.mjs`; всё случайное идёт от одного зерна, поэтому сборка каждый раз даёт одну и ту же карту.

Река течёт слева направо: по воде плывут светлые штрихи — такие же, как нарисованные на картинке волны, только в движении. Русло игра снимает с самой карты, поэтому штрихи повторяют изгибы берегов и огибают причал, а под мостками пропадают. В узких местах вода бежит быстрее, в заводи у причала — тише.

Кадр игры — вся карта целиком, поэтому экран стоит на месте: по локации ходит только герой, камеры нет. Кадр вписан в окно целиком — на экране 16:9 он занимает его весь, на любом другом, в том числе на вертикальном телефоне, по краям остаются поля. Масштаб не меняется.

Всё, что в игре двигается, вырезано с картинки в отдельные текстуры, а место под ним дорисовано скриптом:

- `fisher.png` и `line.png` — сидящий рыбак с удочкой и его леска со всплеском;
- `bucket.png` — ведро с картинки (там оно стоит у дома), вместе с тенью;
- `bucket-carry.png` — то же ведро с поднятой ручкой, для переноски (ручка дорисована);
- `pack.png` — рюкзак с картинки (там он лежит у угла дома): по кадру на каждую расцветку из `shared/src/packs.ts` (под ним дорисованы цоколь, столб и трава); в игре он нужен для выбора рюкзака;
- `pack-ground.png` — те же кадры вдвое меньше: таким рюкзак лежит на земле.

### Дом

Дома с картинки на карте сейчас нет. Сборка вырезает его целиком — с трубой, бочками, ящиками, поленницей и удочкой у стены — и кладёт в `art/house/`, это запас на будущее:

- `house.png` — сам дом на прозрачном фоне, свет в окнах погашен;
- `lights.png` — горящие стёкла окон и фонарь с отсветом на стене, как на картинке; кладётся поверх дома ночью;
- `glow.png` — ореол вокруг стёкол: ночью он разгоняет темноту возле дома и добавляет тёплый свет;
- `house.json` — где дом стоял на картинке, его точка опоры, устье трубы и куда класть свет и ореол.

На месте дома — поляна: вырезанное место ниже линии опушки зарастает травой, выше — лесом (второй ряд крон, стволы, кусты у подножия, кроны опушки). Пока на карте поле (`field`), выше опушки тоже трава. Рисует её тот же `tools/world-sides.mjs` и тем же способом, что бока карты; план — `glade` в `tools/world-shapes.mjs`. По всей поляне можно ходить.

Вернуть дом на прежнее место — одна правка: `house.onMap: true` в `tools/world-shapes.mjs` и `npm run build:world`. Тогда карта собирается с домом, как на картинке, двор снова огибает его, а игра получает `lights.png`, `glow.png` и устье трубы: по ночам в окнах горит свет, из трубы идёт дым (клубы рисует игра; нарисованный на картинке дым с карты стёрт, листва за ним дорисована). Контур дома, окна с фонарём и всё, что стоит у стен, размечены там же, в разделе `house`.

Ходячий герой нарисован кодом в `app/app/game/hero.ts`: голова в три четверти взята с картинки, виды спереди, сзади, шаги, рука с ведром и рюкзак на спине дорисованы той же палитрой. Рыбы нарисованы кодом в `shared/src/fish.ts`.

Поверх карты лежит разметка `tools/world-shapes.mjs`. Её координаты — как у картинки: левее неё x меньше нуля, правее — больше 240, выше — y меньше нуля; в координаты карты их переводит сборка.

- **walk** — многоугольники, где могут стоять ступни героя;
- **solids** — препятствия внутри них (столбик таблички, сваи);
- **occluders** — предметы, за которые можно зайти. У каждого есть строка-опора `base`: пока ступни героя выше неё, предмет рисуется поверх героя. Так он оказывается за табличкой, сваями, кустами и камнями. То же правило работает для ведра.

По полю над рекой и по дороге можно ходить всюду, кроме воды и камней, — до краёв карты, но так, чтобы герой целиком оставался в кадре. Под рекой — только вода.

Скрипт запекает разметку в растры `shared/src/world-data.ts` — по ним и клиент ведёт героя, и сервер проверяет его шаги. Поставленное ведро и снятый рюкзак сами становятся препятствием для своего хозяина: игра закрывает клетки под ними и открывает, когда их берут.

### Как поменять карту или разметку

```bash
npm i --no-save sharp
npm run build:world
```

`sharp` нужен только этому скрипту. С ключом `-- --debug папка` он дополнительно сохраняет картинки с разметкой поверх карты. В самой игре разметку показывает `F2`: белым — где можно ходить, цветом — предметы, которые закрывают героя; в подсказке внизу — координаты под курсором и состояние рыбалки.
