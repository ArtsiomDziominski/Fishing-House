# Fishing House

Уютная пиксельная игра: домик рыбака у реки. Мир взят с картинки-образца один в один, по нему ходит тот самый рыбак в жёлтом плаще — носит ведро и ловит рыбу с причала.

Сейчас в игре есть мир, герой, ведро и рыбалка с пятью видами рыб. Продажи улова, инвентаря и построек пока нет.

## Как запустить

Сборка и зависимости не нужны.

- **Проще всего:** открой `index.html` в браузере.
- **Через локальный сервер:** `npm start` и открой http://localhost:5173.

## Как играть

Игра начинается с кадра, который совпадает с картинкой: рыбак сидит на причале с удочкой, ведро стоит у дома. Чтобы рыбу было куда класть, ведро нужно принести к причалу.

| Действие | Управление |
|---|---|
| Идти | `W` `A` `S` `D` или стрелки; клик или тап по миру — герой сам обойдёт препятствия |
| Взять или поставить ведро | `E` рядом с ведром; клик по ведру; с ведром в руке — клик по герою |
| Сесть рыбачить | `F` или `Пробел` у левого края причала, либо клик по этому месту |
| Забросить и подсечь | `F`, `Пробел` или клик по воде |
| Встать | `Esc`, клавиши движения или клик по земле |
| Масштаб | колесо мыши, `+` / `−` или кнопки в углу |
| Показать разметку | `F2` или адрес с `?debug` |

Все действия продублированы кнопками внизу экрана — на телефоне управление идёт через них и касания.

### Рыбалка

1. Сядь на край причала и забрось удочку. Ведро должно стоять рядом — на причале или у самого берега. Если сесть с ведром в руке, герой сам поставит его рядом.
2. Жди поклёвку: поплавок уйдёт под воду, над героем появится `!`. Бывают ложные тычки — поплавок дёргается, но это ещё не поклёвка.
3. Подсеки, пока рыба не сошла. Дёрнешь раньше — спугнёшь, опоздаешь — сорвётся.
4. Рыба летит в ведро, удочка забрасывается снова.

| Рыба | Как часто клюёт | Вес | Время на подсечку |
|---|---|---|---|
| Плотва | 38% | 90–380 г | 1,25 с |
| Окунь | 26% | 120–650 г | 1,1 с |
| Карась | 20% | 180–950 г | 1,15 с |
| Щука | 11% | 0,9–4,8 кг | 0,85 с |
| Золотая рыбка | 5% | 60–240 г | 0,7 с |

Панель слева вверху показывает, что лежит в ведре. Из ведра торчат хвосты трёх последних пойманных рыб.

### Сохранение

Положение героя, место ведра и улов сохраняются в LocalStorage браузера. Начать заново — открыть игру с `?reset` в адресе. `?save=имя` заводит отдельное сохранение (удобно для проверок, чтобы не трогать основное).

## Как устроен мир

Образец `art/reference.webp` нарисован на сетке 240×320 «арт-пикселей» (по 3,75 px). Скрипт `tools/build-world.js` снимает с него эту сетку — получается чистая пиксельная карта `assets/world.png`, та же картинка без размытых краёв. Игра рисует её целым множителем, поэтому пиксели всегда ровные.

Всё, что в игре двигается, вырезано с картинки в отдельные текстуры, а место под ним дорисовано скриптом:

- `fisher.png` и `line.png` — сидящий рыбак с удочкой и его леска со всплеском;
- `bucket.png` — ведро у дома, как на картинке, вместе с тенью;
- `bucket-carry.png` — то же ведро с поднятой ручкой, для переноски (ручка дорисована).

Пока герой сидит, а ведро стоит на своём месте, кадр равен картинке.

Ходячий герой нарисован кодом в `js/hero.js`: голова в три четверти взята с картинки, виды спереди, сзади, шаги и рука с ведром дорисованы той же палитрой. Рыбы нарисованы кодом в `js/fish.js`.

Поверх карты лежит разметка `tools/world-shapes.js`:

- **walk** — многоугольники, где могут стоять ступни героя;
- **solids** — препятствия внутри них (столбик таблички, сваи, сумка);
- **occluders** — предметы, за которые можно зайти. У каждого есть строка-опора `base`: пока ступни героя выше неё, предмет рисуется поверх героя. Так он оказывается за табличкой, сваями, кустами и камнями. То же правило работает для ведра.

Скрипт запекает разметку в растры `js/world-data.js`. Поставленное ведро само становится препятствием: игра закрывает клетки под ним и открывает, когда его берут. Игре для работы нужны только `assets/` и `js/`.

### Как поменять карту или разметку

```bash
npm i --no-save sharp
npm run build:world
```

`sharp` нужен только этому скрипту. С ключом `--debug папка` он дополнительно сохраняет картинки с разметкой поверх карты. В самой игре разметку показывает `F2`: белым — где можно ходить, цветом — предметы, которые закрывают героя; в подсказке внизу — координаты под курсором и состояние рыбалки.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `css/style.css` | страница, панель улова, сообщения, кнопки, подсказка |
| `js/game.js` | игровой цикл, управление, камера, герой, ведро, сохранение, отрисовка кадра |
| `js/fishing.js` | рыбалка: фазы (заброс, ожидание, поклёвка, вываживание, полёт в ведро) и их отрисовка |
| `js/fish.js` | пять видов рыб: пиксельные карты, шансы, вес, время на подсечку |
| `js/ui.js` | панель улова, всплывающие сообщения, кнопки действий |
| `js/world.js` | проходимость, перекрытие, поиск пути (A*) |
| `js/hero.js` | пиксельные карты героя, кадры ходьбы, рука с ведром |
| `js/world-data.js` | запечённая разметка — генерируется, руками не править |
| `assets/` | карта мира, рыбак, леска, ведро в двух состояниях, значок вкладки |
| `art/reference.webp` | картинка-образец |
| `tools/build-world.js`, `tools/world-shapes.js` | сборка карты и её разметка |
| `tools/serve.js` | локальный сервер |

`README.old.md` — описание прежней версии игры (постройки, работники, торговля); её кода в папке уже нет, текст оставлен как список идей.
