# Пересборка карты

Карту, проходимость и спрайты собирает `tools/build-world.mjs`. Что и по какому плану она рисует — в `tools/CLAUDE.md`. Результат руками не правят (хук не даст): меняется разметка в `tools/world-shapes.mjs` или сама сборка.

1. Сборке нужен `sharp`, в зависимостях его нет:

   ```bash
   npm i --no-save sharp
   ```

2. Собрать:

   ```bash
   npm run build:world
   ```

   В конце сборка печатает строку с размерами всего, что записала, — по ней видно, что изменилось.

3. `app/public/assets/bucket.png` в репозитории лежит правленый, сборка его затирает. Хук после сборки возвращает его сам и сообщает об этом; если хука нет — `git checkout app/public/assets/bucket.png`.

4. Посмотреть, что изменилось: `git status`, `git diff --stat`. Ожидаемо меняются `shared/src/world-data.ts`, картинки в `app/public/assets/` и `art/`. Изменилось что-то, чего правка не касалась, — разобраться, а не коммитить.

5. Проверки: `npm run check` (тесты мира и сохранённых мест читают `world-data.ts`); если сдвинулось что-то проходимое — ещё и `npm run smoke:own -w game-server`: бот ходит по карте.

6. Посмотреть в игре — скилл `verify-game`. Разметку (проходимость, глубину) показывает `F2` или адрес `/play?debug`.

## Что помнить

- Разметка в `world-shapes.mjs` — в координатах картинки-образца, всё в игре — в координатах карты (сдвиг `World.pic`).
- Пересборка меняет `world-data.ts`, и игровой сервер разработки (`tsx watch`) перезапускается: герои откатываются к последнему автосохранению (раз в минуту). Это не ошибка правки.
- Если картинка-образец сдвинулась на карте, сохранённые места игроков перенесёт `cleanWorld` — проверить тестом в `shared/test/players.test.ts`.
